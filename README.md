# Sales Revenue Report – Power BI Project

## Overview
This repository contains a Power BI sales analysis project. The report is built using the provided sales order and detail datasets and is intended to help explore sales performance and revenue trends.

## Files Included
- `Sales Revenue Report.pbix` – Power BI report file.
- `Orders.csv` – Orders dataset.
- `Details.csv` – Sales details dataset.

## Dataset Structure

### Orders.csv
Columns:
- `Order ID`
- `Order Date`
- `CustomerName`
- `State`
- `City`

### Details.csv
Columns:
- `Order ID`
- `Amount`
- `Profit`
- `Quantity`
- `Category`
- `Sub-Category`
- `PaymentMode`

## How to Use
1. Download or clone this repository.
2. Open `Sales Revenue Report.pbix` in Microsoft Power BI Desktop.
3. If Power BI asks for the data source location, point it to the included CSV files.
4. Refresh the data if required.

## Requirements
- Microsoft Power BI Desktop
- The two CSV files included in this repository

## Notes
- Keep the CSV filenames unchanged unless you also update the data source paths in Power BI.
- The report's measures, visuals, and findings can be explored directly in Power BI Desktop.
